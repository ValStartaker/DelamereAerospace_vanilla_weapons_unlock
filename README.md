
# Delamere Aerospace Vanilla Weapons Unlock
## Installation
1. Download the latest version from the Releases tab.
3. Place the .nobp file in `NuclearOption/Bepinex/plugins`, with Blueprinter enabled.

## Description
The three weapons included in this pack were **not created by me**, but rather already existed in the base game files but for whatever reason were not fully implemented. This mod creates internal references to enable them in-game and adds them to appropriate airframe hardpoints.
